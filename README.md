# Many Hands

**Many Hands traces every goal back through every player who caused it, checks each broadcast line for scapegoating, and rewrites it fairly before it airs.**

On 178 real, provider-labelled errors from public match data, Many Hands never flagged deserved blame as unfair (**0 of 130**), and caught the **1 in 4** cases where a single-culprit story would have been. On a synthetic league where the true cause of every goal is known, it matches the simple "blame the last touch" rule on accuracy overall and is **markedly closer to the truth when blame is genuinely shared** (0.37 vs 0.52 distance), with zero false flags in those cases.

Built for the Inside the Game Developer Hackathon (Microsoft and the Premier League). All match data in the product is synthetic and fictional.

## Why
Football is a team game, but when a goal goes in, TV graphics, pundits and AI recaps usually name one culprit. Reporters' ratings are biased by the result (Kausel et al. 2019), and online abuse of Premier League players peaks right after key match moments, with 68 percent of players abused in half a season (Alan Turing Institute for Ofcom, 2022). Platforms remove abuse after it is posted. Many Hands works earlier, on the story itself.

## What it does (the five required stages)
| Stage | Many Hands |
|---|---|
| Ingest | Match events as a live stream, from our calibrated simulator or your own provider files |
| Interpret | Every action valued with a published model (VAEP, Decroos et al. 2019); each player's share of every decisive moment |
| Explain | Why this player and not that one; the unsung attacker who created the chance |
| Render | Timed graphics: chain strip, responsibility bars, Unsung card |
| Personalize | Versions by depth, club, featured player and language, each one checked for fairness |

The check is the **Scapegoat Index**: the gap between who a sentence blames and who the evidence says contributed, from 0 (fair) to 1 (fully misplaced). Fair below 0.20, Watch to 0.40, Unfair above. Blaming one player alone is fine when that player really carried the moment: fair both ways.

## Try it in two minutes
```
uv sync
uv run uvicorn services.api.app:app --port 8000      # REST API with OpenAPI docs at /docs
uv run python packages/sdk/manyhands/cli.py matches
uv run python packages/sdk/manyhands/cli.py chains 20003
uv run python packages/sdk/manyhands/cli.py audit 20003-150 "Number 5's howler cost them the game."
uv run python services/api/mcp_server.py --http      # the ledger as MCP tools
```

## The numbers, and how to rerun them
| Benchmark | Cases | Result |
|---|---|---|
| [External](benchmarks/external_statsbomb/RESULTS.md): StatsBomb Open Data, non Premier League, provider-labelled errors | 178 | 0 of 130 false Unfair flags on justified blame; labelled player in our top three 80% (last-touch 92%); 27% of single-culprit lines would be Unfair |
| [Synthetic](benchmarks/synthetic/RESULTS.md): 60 fictional matches with counterfactual ground truth | 483 moments | Distance to truth 0.148 (last-touch 0.148); on 42 shared-blame moments 0.37 vs 0.52 with 0 false flags |

Measured limits: last-touch names the main culprit more often than our ledger (85 vs 79 percent on synthetic, 90 vs 76 percent on real data); off-ball positional blame did not improve results at any weight, so its weight is 0; 91 percent of synthetic moments have one dominant cause.

```
uv run python packages/sdk/manyhands/cli.py verify --suite synthetic
uv run python packages/sdk/manyhands/cli.py verify --suite external
```
